# UCI HAPT sensor replay subset

Dataset: *Smartphone-Based Recognition of Human Activities and Postural Transitions*, Jorge L. Reyes-Ortiz, Davide Anguita, Luca Oneto and Xavier Parra (2015).

Source: UCI Machine Learning Repository, https://doi.org/10.24432/C54G7M.
License: Creative Commons Attribution 4.0 International (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/.

MoveSmart uses this public dataset for bundled sensor playback, not as measurements of the signed-in user. The CSV is a modified 150-sample subset of experiment 01, participant 01: paired accelerometer/gyroscope rows 500–549, 7650–7699 and 13300–13349, with activity labels and a rebuilt 20 ms timeline. Accelerometer units are g; gyroscope units are rad/s. No endorsement by the dataset authors is implied.
